P0 功能与运行说明

已实现：
1. 首页模型下拉选择及右侧模型配置面板。支持兼容 OpenAI 聊天接口的服务。
   可新增、编辑、删除、测试连接；编辑时 API Key 留空保留原密钥。
   启动时仅首次导入 backend/.env；之后以模型管理中保存的配置为准。
   开始研究时固定所选配置，后续编辑或删除配置不改变运行中的研究。
2. 首页与研究页共用历史列表，支持搜索、打开、重命名和确认删除。
   新版本发起的研究保存到 backend/data/research.sqlite3。
   旧 notes 文件保留原位；本次没有将旧笔记推断成完整研究历史。
   页面切换、刷新或关闭不取消后台研究，前提是后端进程继续运行。
   后端重启后，未完成研究标为中断；已保存内容保留，不会自动重跑。
   运行中的记录不能删除；删除历史不删除独立的 notes 文件。
3. 研究页左侧在原进度区域下方显示总耗时、规划、并发执行和报告耗时。
   展开各子任务耗时可查看搜索和总结时间。计时由后端单调时钟采集。
   并发执行阶段是实际经过时间，不是各任务耗时相加。
   完成、失败时冻结计时；中断时保留最后保存的时间，未执行阶段显示横线。
   不展示 Token 用量、费用或余额。模型配置中的最大输出长度是调用参数。

前后端联通：
- GET/POST /model-profiles；PUT/DELETE /model-profiles/{id}；POST /model-profiles/{id}/test
- POST /research-runs：固定配置后启动后台研究，返回研究 ID
- GET /research-runs：历史列表；GET /research-runs/{id}?after=N：增量进度与计时
- PATCH/DELETE /research-runs/{id}：改名与删除
- 前端每秒读取已保存的新增事件，复用原有详情展示逻辑。
- 旧 /research 和 /research/stream 接口保留兼容；完整历史请通过新首页发起。

文件：
- backend/data/ 仅存于本机，包含密钥配置，请勿分享或提交；已加入 .gitignore。
- 每次新研究的笔记分开保存到 backend/notes/{research_id}/。
- 旧源文件备份在 .runtime/p0-before/。
