完整安装、API 配置、OpenAlex 导入和故障排查请阅读根目录 README.md。

首次安装顺序：
1. 使用 Python 3.11 创建 backend/.venv。
2. 安装 backend/requirements.local.txt。
3. 执行 npm.cmd --prefix frontend ci。
4. 复制 backend/.env.example 和 frontend/.env.example。
5. 在 backend/.env 或首页模型配置中填写自己的 API Key。
6. 执行 .\start-local.cmd，打开 http://127.0.0.1:5174/。

shared-data 历史导入和 OpenAlex 数据导入都是可选步骤，不影响空数据库启动。
停止服务请执行 .\stop-local.cmd。不要复制其他电脑的 .venv、node_modules、.env 或数据库。
