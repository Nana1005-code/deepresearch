# 主题知识图谱

- 节点：全局唯一的标准主题；大小表示筛选周期内热度，颜色按“相对上一周期增长率”在当前图中的分位数着色，避免热度接近时全部同色。
- 边：两个主题在同一篇公开研究中共同出现。
- 边权：Jaccard 系数，即共同研究数除以两个主题研究集合的并集数量。
- 全局图谱：先按热度选择前 N 个主题，再按 Jaccard 与共同研究数排序；每个节点只保留最多 3 条最强关系。
- 领域图谱：先通过 `topic_domains` 限定领域，再执行同一算法。

前端使用 ECharts `graph` 的 force 布局。支持节点拖动、滚轮缩放、画布平移、邻接高亮、关系提示和重置视图。节点可点击并自动生成“相关主题”热点问题。

同一个主题可通过 `topic_domains` 同时属于多个领域，并在节点提示中展示全部归属。跨领域主题仍然只有一个节点，不按领域复制。
