所有模拟研究标题均带 `[模拟]`。

## 一致性审计

审计通过：外键无异常；点赞/收藏缓存与明细一致；知识图谱边方向和权重合法；隐藏研究未进入当前模拟统计。

## 并发烟雾测试

本机同时使用 24 个线程执行 200 次查询和 50 次浏览写入：

- 250 个请求，0 错误
- 总吞吐量约 42.6 请求/秒
- 读取 P50 约 113.67 ms，P95 约 2396.88 ms
- 写入 P50 约 12.59 ms，P95 约 57.73 ms

该结果只代表当前电脑上的 SQLite 开发环境。图谱查询造成的读取尾延迟说明后续正式部署前应增加缓存，并在本地 MySQL 和最终服务器上重新压测。

## 自动测试

- 新模块 12 项测试通过，包括 40 个线程任务并发点赞、别名归一、跨领域归属、自由文本主题识别、错误计划修复、90 天三周期趋势、OpenAlex 表隔离与去重统计、禁止无主题热榜降级和图谱稀疏化。
- 前端 TypeScript 检查与生产构建通过；研究广场与 ECharts 被构建为独立异步资源。

OpenAlex 匿名接口已实际导入 1 条元数据和 3 个主题，接口报告成本 `$0.0001`；记录进入独立 `openalex_*` 表，模拟及用户公开数据数量未被覆盖。默认筛选已排除发布日期晚于当天的记录。

随后已由用户完成 10,000 条真实元数据导入，OpenAlex 报告成本 `$0.01`。当前包含 3,860 个唯一 OpenAlex 主题和 29,925 条论文—主题映射；批量 AI 中文别名、跨领域增强和低置信度复核采用可恢复任务执行。

批量 AI 增强最终结果：

- 3,860 / 3,860 个 OpenAlex 主题完成中文规范名与内部领域映射。
- 生成 11,152 条中文别名。
- 1,218 / 1,218 篇主主题分数低于 0.5 的论文完成候选复核。
- 728 篇仍标记为需要人工审核；模型建议没有覆盖 OpenAlex 原始主题。
- 37 个主题因中文名冲突或较低置信度进入主题审核队列。
- 不属于八个核心领域的主题使用“综合”兜底，不强行归入人工智能等领域。
- 已记录的成功批次消耗 777,763 输入 token 和 311,006 输出 token；一次人工中断批次的 token 未被接口任务表记录。
- 原有模型输出、重试、搜索容错、计时和公开答案等非 TestClient 测试通过。
- 当前 Windows/Python 环境下，原仓库若干既有 FastAPI `TestClient` 并发测试会停在首个请求；相同现象也出现在未经过研究广场路由的测试模块，因此记录为既有测试运行器问题，不以跳过方式声称通过。
