# 修改点 003：首页入口与公开操作

- 修改文件：`frontend/src/App.vue`
- 修改内容：增加“研究广场”模式入口、加载独立页面组件，并在已完成研究中增加“公开到研究广场”按钮。
- 原因：新模块需要一个导航接入点，也需要由用户主动触发公开。
- 隐私：公开前询问标签、是否公开完整报告和是否匿名；默认不会自动公开任何历史研究。
- 对现有功能影响：新研究、对话、笔记、历史和全屏研究页面的原状态变量及处理函数未改写。研究广场使用新的 `homeMode='square'` 分支。
- 撤销方式：删除新增组件 import、第三个按钮、页面组件、公开按钮与两个新增函数。
- 验证：前端 TypeScript 构建、原有后端回归测试、手工验证三种首页模式切换。
