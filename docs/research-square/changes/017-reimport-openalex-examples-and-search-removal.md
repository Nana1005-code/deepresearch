# 017 取消导入后恢复、问答样例与搜索移除

## 修改范围

- `backend/src/research_square/store.py`
- `backend/src/research_square/router.py`
- `backend/tests/test_research_square.py`
- `frontend/src/features/research-square/ResearchSquarePage.vue`

## 1. 修复取消导入后无法再次导入

取消导入仍保留本机原始研究记录、已提取关键词和图谱关系，只把广场记录状态改为 `hidden`。再次导入同一个历史研究时，后端现在直接把该记录恢复为 `published`，并复用原关键词和连线，不再创建 DeepSeek 提取任务。

这样即使模型 API 暂时无效，已经成功导入过的研究也可以立即恢复。只有从未成功提取过关键词的记录才继续走后台 AI 导入队列。

## 2. 恢复真实学术问答样例

真实学术图谱的问答助手增加六类可点击样例，覆盖热点排行、主题关联、时间趋势、主题比较、领域论文和领域概括。点击样例会填入输入框，用户仍需确认后发送。

个人图谱的“研究遗漏助手”保持单一用途，不恢复多类型提示词。

## 3. 移除列表搜索界面

删除页面顶部的“搜索我的导入记录/搜索真实研究论文”输入框和搜索按钮，只保留图谱类型切换。真实论文列表继续展示本机 OpenAlex 数据，但不再暴露未完成的搜索交互。
