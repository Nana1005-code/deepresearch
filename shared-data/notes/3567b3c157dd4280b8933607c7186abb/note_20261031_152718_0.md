## 已收集信息
### 来源与证据
1. **NMM Roadmap: Toward Native Multimodal Modeling (arXiv 2605.25343, Tencent Youtu Lab, 2026-05-25)** — 提出原生多模态建模(NMM)的形式化路线图。核心贡献：正式定义"架构原生性"，区分 late-fusion / mid-fusion / early-fusion 三阶段；按输入-输出对偶性将原生模型分为三类：M2T (Multi-to-Text，跨模态理解)、M2G (Multi-to-Target，场景化生成)、M2M (Multi-to-Multi，对称统一建模)。图1给出范式演进：late-fusion 是解耦的"connect-and-generate"，各模态独立编码器+嫁接输出头；mid-fusion 是集成但保留显式模态边界；early-fusion 是 born-native，所有模态在共享嵌入空间由单一原生 transformer 处理。系统性覆盖架构协同、海量数据策展、全栈训练配方(PT/SFT/RL/OPD)、推理部署与评估。
2. **Awesome-Multimodal-Modeling (OpenEnvision/Awesome-Multimodal-Modeling, GitHub, 最后更新 2026-10-19)** — 551 stars, 33 forks, 160 commits。覆盖 MLLM/UMM/NMM 的综述与精选列表。关键条目：Tuna-2 (arXiv 2604.24763, 2026) — 原生统一多模态模型，**抛弃传统视觉编码器**，改用直接像素嵌入做端到端理解与生成；NEO (arXiv 2025) — 规模化原生视觉-语言原语，配套可复用组件；Qwen3.5-Omni (Qwen Blog 2026) — 离散原生任意分辨率视觉 transformer + omni 模态扩展；ERNIE 5.0 Technical Report (arXiv 2026, late fusion) — 原生自回归基础模型，覆盖文本/图像/视频/音频统一理解与生成；PixelUMM (arXiv 2609.01607, 2026-09-29) — 首个公开的 encoder-free MoT，将原始图像 patch/视频 tubelet 直接投影进共享多模态注意力，AR 文本建模 + 像素空间 flow matching 提供理解与视觉生成，架构原生但以 Qwen3-8B 初始化而非全组件 from scratch；截至 2026-10-19 代码与 checkpoint 已发布。
3. **Uncovering Understanding–Generation Synergy in Native Unified Multimodal Models (arXiv 2609.01607v1)** — 在受控原生设置(无预训练视觉先验，pixel-in/pixel-out，无视觉编码器、无 image tokenizer/VAE)下从表征/任务/系统三层研究 UMM 的理解-生成关系。核心发现：(a) 表征层：生成监督丰富理解所需视觉特征，理解强化生成的视觉-语言对齐，双目标互为正信号；(b) 但强制走同一计算路径时会出现不对称退化——dense shared model 联合训练提升理解却损害生成，modality-decoupled MoT (文本留 LLM 分支、视觉 token 走从头初始化的独立分支) 提升生成却损害理解；(c) 提出 task-decoupled MoT：理解视觉 token 留语言分支、生成视觉 token 归专门分支，实现软对齐，两能力共存不互损；(d) 任务层：几何推理/矢量图形/3D 空间智能三个案例显示共享知识时存在正向双向迁移，几何配对训练还提升通用数学推理；(e) 系统层：端到端 UMM 在需要理解+生成的复杂任务(推理密集型图像编辑)上优于匹配的 planner–executor 智能体流水线。使用 SenseNova-U1 数据，单阶段训练 210k steps，lr=1e-4。
4. **Native Multimodal Models (NMMs) — emergentmind 专题 (更新于 2026-02-22)** — NMM 定义：端到端训练、跨模态联合感知/处理/生成的统一架构，无需单独预训练编码器、adapter 模块或 late-fusion 头。所有模态表示为共享空间的 token/embedding，由单一序列建模栈处理。关键架构变体：early-fusion(输入层即合并所有模态，所有 transformer block 从第一层起联合混合)、dense unified backbone(无深度上的模态分支)、sparse MoE(激活模态专用专家权重)。共同特征：跨所有模态的共享 next-token 目标、端到端优化(scratch 或强 LLM 初始化)、统一 tokenization 与位置方案(广义 RoPE 支持 1D 时序 + 2D/3D 空间/体积对齐)。规模化法则：等算力下 early-fusion 与 late-fusion 相当或更优；dense 最优 N∝C^0.53，MoE 最优 N∝C^0.36、D∝C^0.66；Aria 每 token 仅激活 ~8/66 专家。长上下文(64k)与高分辨率通过 RoPE 频率基与 patchification 方案扩展。
5. **How Multimodal LLMs Work in 2026: A Visual Guide (Future AGI, 2026-05)** — 传统(非原生)2026 主流设计仍是"视觉编码器 + 连接器 + 文本解码器"三段式。主流编码器：CLIP ViT-L/14(24 层, 224/336px)、SigLIP(sigmoid loss, 更高数据效率)、InternViT-6B-448px、Pixtral-ViT(1B, 专为可变分辨率)。三种融合策略：投影式连接器(LLaVA/NVLM 双层 MLP + GeLU/ReLU；Pixtral Large 轻量线性投影 + image-token marker，token 数等于 patch 数)、Q-Former(BLIP-2/InstructBLIP，可学习 transformer 压缩 N→K 个 query token，K=32)、cross-attention adapter(Flamingo/OpenFlamingo，在冻结 LLM 的自注意力层间插入交叉注意力，语言 token 作 query、视觉 token 作 key/value)。解码器主流：Llama 3/4、Qwen2/Qwen3、Mistral/Mixtral、Vicuna。Pixtral Large 关键技巧：block-diagonal attention mask + 2D RoPE 处理可变图像尺寸，上下文达 128k。

## 关键发现
1. **范式三阶段与原生性形式化**：late-fusion → mid-fusion → early-fusion(born-native)，架构原生性已有形式化定义与 M2T/M2G/M2M 分类。
2. **去视觉编码器(encoder-free)成为 2026 标志性方向**：Tuna-2 用直接像素嵌入，PixelUMM 用 encoder-free MoT 直投影 raw patch/tubelet，pixel-in/pixel-out 成为原生 UMM 的标准受控设置。
3. **统一理解-生成不是免费午餐**：功能统一 ≠ 学习协同；需要任务解耦的 MoT/双分支软对齐才能避免不对称退化，共享知识任务才有正向迁移。
4. **MoE 稀疏化既扩规模又保模态专用容量**：Aria ~8/66 专家/token；scaling law 显示 MoE 数据需求更陡(D∝C^0.66)而参数需求更缓(N∝C^0.36)。
5. **任意分辨率/长上下文已成工程标配**：RoPE-2D/广义 RoPE、block-diagonal attention mask、patchification 让 64k–128k 上下文与可变分辨率/长视频可行。
6. **传统 late-fusion 三段式与原生架构在公司级 production 中并存**：2026 年 GPT-5 vision、Claude Opus 4.7、Gemini 3、Pixtral Large、NVLM 1.0、LLaVA-NeXT 仍广泛采用编码器+连接器+解码器。
