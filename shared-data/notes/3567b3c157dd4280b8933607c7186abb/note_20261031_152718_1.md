# 任务 2: 训练范式与数据

# 任务 2: 训练范式与数据

## 目标
调研 2026 年多模态预训练与后训练范式：交错图文视频语料构建、合成数据与数据配比、多模态对齐/指令微调/RLVR。

## 已有发现

### 1) 训练范式从"预训练+RLHF"两段式裂变为"预训练 / 能力塑形 / 对齐塑形"三段式
- Richard Kelley (2026-early) 提出三阶段划分，并用六个判别维度刻画每一阶段：Objective、Data regime、Loss function、Output、Resulting properties、Compute allocation。
  - Pre-Training：自监督下一 token 预测，海量弱过滤语料，自回归交叉熵，产出 foundation model，占据绝大部分算力。
  - Capability Shaping：更 curated/域定向语料（code/math、long-context），继续预训练式交叉熵，算力占比"较小但仍有意义"。
  - Alignment Shaping：人工示范 + 排序输出 + 策略/奖励反馈；损失 = SFT 模仿损失 + 奖励/偏好驱动目标（RLHF/RLAIF/RLVR/DPO 系）。
- 子阶段清单（capability）：context extension、code/math corpora training、synthetic reasoning training、multilingual balancing、tool-use corpora。
- 子阶段清单（alignment）：SFT、RLHF、RLVR、DPO、Tool-Augmented Reward Modeling。
- 关键结构性判断：capability 与 alignment 之间是**反馈回路**（对齐过程暴露能力缺口→回到能力塑形），而非单向流水线；RLHF 与 DPO 之间近似 **XOR**（同一问题的互斥解法），且子阶段无唯一顺序（context extension 大概率最先）。
- 算力/能力分配判断：后训练（SFT+偏好优化+RL）已占模型"可用能力"的多数，预训练只提供底座。

### 2) 后训练技术栈完成代际替换：GRPO/DAPO 取代 PPO，DPO 系持续"去依赖"
- GRPO（DeepSeekMath→DeepSeek-R1）：去掉 critic，每 prompt 采样 8–64 条响应，组内归一化 advantage =(reward_i − mean)/std。理论侧：arXiv 2603.01162 证明其策略梯度是 U-statistic，与拥有理想 value function 的 oracle 算法渐近等价——不是启发式 trick。
- DAPO（ByteDance/清华 2025）：针对长 CoT 的四种稳定性技术（clip-higher、动态采样、token-level loss、超长惩罚——原文被截断，仅列项）；AIME 2024 上把 Qwen2.5-32B 训到 50 分，超过 DeepSeek-R1-Zero 且训练步数少 50%，系统已开源。
- 偏好优化三代演进，每一代删掉一个依赖：DPO（需 reference model + 成对偏好）→ SimPO（用响应平均 log prob 作隐式奖励，去掉 reference model，AlpacaEval 2 +6.4、Arena-Hard +7.5）→ KTO（二元 thumbs up/down，去成对数据）→ ORPO（odds ratio 合并 SFT 与偏好优化，去独立 SFT 阶段、消除 SFT→偏好调优的分布漂移）。
- SFT 规模经验值：1–10M curated examples；Nemotron 3 Super 从 40M 语料中筛 7M 样本（约 17.5% 保留率）。

### 3) RLVR 成为推理能力主引擎，但"验证器质量"与"感知盲区"是两大真问题
- DeepSeek-R1 证明纯 RLVR 可涌现自我反思与策略自适应，无需人工推理轨迹标注；奖励来自单元测试/证明检查器/数学验证器。
- RISE：把"解题"与"自我验证"放进同一 RL 过程，用同一可验证奖励信号训练二者，使模型推理时可自查错误。
- 噪声验证器去偏：数学检查器有边界情况、代码测试不完备，需 correction 算法对观测奖励去偏，防止模型利用假阳性刷分。
- 多模态特有瓶颈（ICLR 2026, Perception-R1）：用 McNemar 检验发现**现有 RLVR 无法有效提升 MLLM 的感知能力**，从而卡住多模态推理上限；解法是引入视觉感知奖励（perception reward）。这是"文本 RLVR 成功经验不能平移到多模态"的直接反例。

### 4) 数据侧：合成自博弈 + 文档接地，破解人工标注瓶颈与模型崩塌
- SPIN（UCLA 2024）：模型判别自身输出与人类输出，无需新增人工标注，效果匹敌/超过 DPO。
- SPICE：Challenger 从外部文档挖 reasoning 任务，Reasoner 求解——文档接地抑制了无接地自博弈的幻觉放大与模型崩塌；数学 +8.9%、通用推理 +9.8%。
- 交错数据不再是"图文对"，而是 text / video / image-text pairs / **action-conditioned video** 的混合序列（Transfusion 式：语言用 next-token CE，视觉用 frame-wise flow matching，逐帧独立采 t∼U[0,1] 加噪）。
- 数据配比结论（arXiv 2603.03276，from-scratch 受控实验）：视觉与语言数据间**干扰极小、部分场景正协同**；IsoFLOP 揭示 **scaling 不对称——视觉远比语言"吃数据"**；MoE 提供语言所需高容量同时容纳视觉的数据密集特性，从而弥合该不对称，并自然诱发模态专门化（modality specialization）。
- 统一多模态预训练自然涌现 world modeling（Navigation World Model 上把 action 直接格式化为 text token，物理预测能力主要来自通用多模态预训练而非领域数据）。

### 5) 工程实践细节（可直接复用的配方参数）
- 视觉表征选择：RAE（Representation Autoencoder）在理解与生成两侧均最优（对比 VAE / 语义表征 / raw pixels）。
- 多模态 SFT 配方：encoder 冻结，Cambrian-7M 训 1 epoch，64 GPUs，global batch ≈1M tokens，peak LR 1e-5。
- 纯文本模型转多模态：先在 Cambrian-Alignment 上 warm up vision adapter（其余冻结），peak LR 2e-3，再进入同一多模态配方。
- 位置编码（ICLR 2026）：三条准则——positional coherence、full frequency utilization、preservation of textual priors；MHRoPE / MRoPE-I 为即插即用改法，无需改架构。
- 交错推理范式：IRG（文本思考→出图→反思精修）、TumorChain（findings→impressions→病理预测的交错多模态 CoT）、Cosmos Policy（预训练视频模型单阶段 post-train 成机器人策略，无架构改动）。
