## 本轮新增发现（第 2 轮分析）

### 发现 1：多模态智能体正在从"模型能力"演变为"系统能力"，技术栈已分层
- 现象：本轮素材分别命中四层——模型层（Nemotron 3 Nano Omni / Reka Core）、检索层（Ragie 音视频 RAG）、协议层（MCP 1.0 server）、基础设施层（Vultr GPU 集群 + serverless 推理）。
- 含义：2026 年多模态智能体的竞争焦点不再是单点模型分数，而是"模型—检索—协议—推理/部署"四层能否协同闭环。
- 价值：解释了为何 Vultr 这类云商与 NVIDIA 的联合发布被当作独立新闻事件——分发与推理成本已成为 Agent 落地的实际瓶颈。
- 工程含义：开发者需要同时做模型选型、索引管线、工具协议和推理托管四类决策，Agent 工程复杂度显著高于单纯调用 LLM。

### 发现 2：MCP 成为多模态检索与智能体之间的"总线协议"，架构语义发生迁移
- 关键事实：Ragie 明确对比"多数 MCP server 只支持单一集成"，而其 1.0 版允许 MCP 客户端在**单次工具调用**中跨多源检索组织全知识库。
- 原理层面：这是把"多跳检索编排"从 Agent 侧的 Planner 内化到 Tool 侧，减少 LLM 与工具之间的往返轮次，直接降低时延与 token 消耗，也降低规划错误的累积概率。
- 应用价值：企业知识库（文档+音视频+数据库）可用一个工具入口暴露给任意 MCP 客户端，降低 Agent 侧的集成维护成本（M×N → M+N）。
- 风险/权衡：单次调用返回全部知识库意味着检索精度与上下文爆炸风险的权衡；召回质量从"可解释的多步"变为"黑盒单步"，可观测性下降。

### 发现 3：模态前沿已从"图像理解"推进到"音视频原生检索 + 时间戳定位"
- 事实：Ragie 支持上传任意音视频，提问后可从答案来源的**精确时刻**流式回放（stream from the exact moment it came from）。
- 原理含义：这要求时间轴切分（temporal segmentation）+ 跨模态联合嵌入（joint embedding）+ 时间戳对齐三件套，难度明显高于静态图像 RAG。
- 对比：图像 RAG 的粒度是"页/区域"，音频视频 RAG 的粒度是"时间段"，索引成本、存储成本和评测复杂度都上一个量级。
- 垂直场景（素材明确列举）：企业培训/在线学习、媒体视频分析与生产、医疗研究与医患交互分析、法律庭审与证言调取、客户支持。
- 价值：音视频占企业非结构化数据的大头，长期是 RAG 的"盲区"，原生支持意味着可寻址数据总量出现结构性扩张。

### 发现 4：部署弹性（on-device / on-prem / API）成为多模态模型的硬性竞争维度
- 事实：Reka 三模型（Edge/Flash/Core）同时提供 API、本地部署、端侧部署；Vultr 提供专用 GPU 集群与 serverless 两条路径；Nemotron 3 **Nano** Omni 的"Nano"命名指向效率优先的小尺寸 Omni 模型。
- 原理层面：端侧/小尺寸 Omni 意味着音频、视觉编码器与 LLM 主干被联合压缩，配合量化与蒸馏（如 Reka 相关系列工作 EdgeQ），在总拥有成本（TCO）上换取竞争力。
- 应用含义：端侧能力是具身智能与车载智能体的前置条件——必须在本地完成低时延闭环感知，无法依赖云端往返。
- 与汽车/具身线索的耦合：中国汽车多模态交互报告明确指出，基础模型与多模态融合将推动 AI Agent 上车，其能力提升来自"感知与环境理解"（视觉+听觉+语言），这正是端侧 Omni 的用武之地。
- 权衡：端侧 = 低时延、隐私合规、离线可用；但牺牲上下文长度与峰值推理能力，通常需要"端侧小模型 + 云端大模型"的级联架构。

### 发现 5：落地形态可归纳为"车载/具身、企业知识库 Agent、垂直行业 SaaS"三类，但量化证据严重不足
- 三类形态：(a) 物理世界智能体（汽车座舱、机器人）；(b) 企业知识/流程智能体（Ragie + MCP + 云基础设施）；(c) 垂直行业嵌入式能力（电商、社媒、游戏、医疗、法律）。
- 缺口：本轮素材未提供任何时延（ms）、单次调用成本（$）、准确率（%）或 GUI 智能体的基准分数（如 OSWorld / WebArena 类指标）。
- 特别是：任务目标中的 **GUI / Computer-Use Agent 完全未被命中**；**具身智能**仅通过汽车场景间接覆盖，缺少 VLA（Vision-Language-Action）模型与机器人数据集的一手证据。
- 结论：当前证据级别是"产业信号"而非"研究文献"，不可直接用于支撑 2026 年研究现状的量化论断。
