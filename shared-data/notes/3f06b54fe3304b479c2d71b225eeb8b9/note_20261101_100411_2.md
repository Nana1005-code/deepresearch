# 任务 3: 评测基准与能力

【任务概览】梳理2025年多模态能力评测基准与 SOTA 变化。
【核心意图】识别2025年新增的评测维度（长视频、GUI/Agent、空间与具身推理、文档图表、幻觉）及真实能力提升幅度，辨别刷榜水分。
【检索方向】MMMU-Pro / MMBench / Video-MME / MathVista 2025 leaderboard; multimodal hallucination benchmark; GUI agent benchmark OSWorld; spatial reasoning VSI-Bench 2025。
【预期产出】基准—能力维度映射表，以及各维度2024→2025 进展判断。
【边界】不重复模型发布信息（任务2），不展开训练方法（任务4）。
