# P0验收报告：Python asyncio 的主要用途

## 1. 背景概览
asyncio 是 Python 标准库中基于 async/await 语法编写并发代码的模块，官方定位为构建 IO 密集型、高层级结构化网络代码的最佳选择，也是 aiohttp、FastAPI 等高性能异步框架的底座 [任务1]。

## 2. 核心洞见
- 高层级 API 覆盖五大用途：并发运行协程（asyncio.run/create_task/gather/TaskGroup）、网络 IO 与 IPC（流）、控制子进程、用队列实现分布式任务、同步原语协调并发 [任务1]。
- 低层级 API 供框架开发者管理事件循环、transports/protocols 高效协议，并桥接回调式代码 [任务1]。
- CPU 密集型任务可通过 run_in_executor 配合进程池执行 [任务1]。

## 3. 证据与数据
- 3.7 引入 asyncio.run()；3.11 起引入 TaskGroup 与 asyncio.timeout 实现结构化并发，任务取消更安全 [任务1]。

## 4. 风险与挑战
- 事件循环仅保留任务弱引用，需保存强引用或用 TaskGroup 防止任务被 GC [任务1]。
- CancelledError 直接继承 BaseException，官方推荐用 try/finally 做清理 [任务1]。
