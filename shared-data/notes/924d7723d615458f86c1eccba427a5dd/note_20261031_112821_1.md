# 研究报告：P0验收：Python asyncio 的主要用途。请仅创建1个子任务，优先检索Python官方文档，最终报告控制在300字以内。

## 1. 背景概览
asyncio 是 Python 标准库中基于事件循环的异步 I/O 框架（3.4 引入），官方定位为编写并发代码的基础设施，核心价值在高并发 I/O 场景。

## 2. 核心洞见
- 主要用于并发执行 I/O 绑定任务，以单线程事件循环与协程避免阻塞及线程开销（任务1）。
- 提供协程与任务调度能力，如 `asyncio.run()`、Task、TaskGroup（任务1）。
- 覆盖网络通信（Streams）、子进程（Subprocesses）、队列（Queues）与同步原语（任务1）。
- 不适用于 CPU 密集型并行，官方建议改用多进程（任务1）。

## 3. 证据与数据
官方文档章节即为依据：Asynchronous I/O、Coroutines and Tasks、Streams、Synchronization Primitives、Subprocesses、Queues；HOWTO 与“用 asyncio 开发”强调避免阻塞事件循环（任务1）。

## 4. 风险与挑战
CPU 密集任务会阻塞事件循环；需处理取消、异常与调试；跨版本 API 存在差异（如 TaskGroup 3.11+）。暂无实测性能数据。
