# Python asyncio 主要用途研究报告

## 1. 背景概览
asyncio 是 Python 官方提供的异步 I/O、事件循环、协程与任务基础设施，主要用于单线程高并发 I/O 编程 [任务1]。

## 2. 核心洞见
- 官方定位：编写单线程并发代码的基础设施，通过协程复用 socket 等 I/O [任务1]。
- 能力包括：可插拔事件循环、transport/protocol、TCP/UDP/SSL、子进程管道、Future、Task、取消机制及同步原语 [任务1]。
- 典型场景：网络服务端/客户端、socket 多路复用、子进程管道等高并发 I/O [任务1]。
- 阻塞库可交由线程池执行；CPU 密集任务不适用 [任务1]。

## 3. 证据与数据
Python 3.4/3.5/3.6 官方文档均将 asyncio 描述为异步 I/O、事件循环、协程与任务模块，并说明其基于 `yield from`（PEP 380）实现协程 [任务1]。

## 4. 风险与挑战
异步编程比顺序编程更复杂；若阻塞事件循环会损害并发性能，开发期建议开启 debug 模式；早期版本曾为 provisional 包，允许不兼容变更 [任务1]。
