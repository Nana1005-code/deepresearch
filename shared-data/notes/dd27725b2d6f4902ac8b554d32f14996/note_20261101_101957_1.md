# 任务 2: 训练与对齐方法

任务概览：调研2026年多模态大模型的预训练数据构建、训练范式与对齐技术。系统提示：关注数据规模与配比、跨模态对齐、指令微调、RLHF/RLVR、思维链多模态推理训练。来源概览：arXiv、技术报告、开源数据集与训练框架。

任务总结（2026 训练与对齐方法）：
1. 预训练数据配方（data-centric recipe）：1T token 规模预训练 + 100+ 对照实验 + 50 万 GPU 小时证明，能力对视觉编码器与视觉指令微调数据最敏感，描述视觉世界的文本收益迅速饱和；数据受限场景下最优 weight decay 达常规 30 倍，数据课程需与优化方法协同设计。
2. 跨模态对齐焦点从连接器转向位置编码：ICLR 2026 提出位置一致性、全频段利用、文本先验保持三准则，MHRoPE 与 MRoPE-I 为即插即用方案。
3. 后训练（MMPoT）五大家族：instruction following、preference calibration、reasoning enhancement、domain adaptation、scalable training（同济+Qwen 综述，2026-07 预印本）；SFT 模仿学习无法判断偏好/证据/安全/稳健，RL 成为关键；演进 PPO→DPO→GRPO。
4. RLVR 多模态化暴露感知瓶颈：Perception-R1 用 McNemar 检验证明 RLVR 无法增强感知，提出视觉感知奖励；DECS 指出长度奖励两大缺陷（误罚探索 token、误奖冗余 token），用解耦 token 级奖励 + 课程批次调度，7 基准推理 token 减少 50%+ 且性能不降；Fine-R1 用 R1 风格框架做细粒度视觉识别。
5. 对齐管线平台化：Dataiku 给出 RLHF（DPO 优于 PPO）、RLAIF（GPT-5/Claude 4 Sonnet 作裁判）、RLVR（gsm8k 三步工作流）可编排实现。
6. 隐私与对齐交叉：相同 DP 保证下，适配数据越接近预训练分布实际风险越高（即使无重叠）；LoRA 等 PEFT 对 OOD 数据经验隐私保护最好；需覆盖预训练—适配全流程评估。
7. 生成式对齐新范式：扩散模型 RLR（半阶微调）通过递归扩散链计算图重排实现低方差无偏梯度，图像/视频生成验证有效。

综合判断：数据侧从堆量转向配方；对齐侧位置编码等隐性基础设施回潮、后训练形成五大家族、RLVR 需感知奖励与 token 级解耦奖励补足；工程侧 RLHF/RLAIF/RLVR 平台化、DPO 成默认选择，隐私/过度思考/样本效率等二阶问题被系统性研究。
