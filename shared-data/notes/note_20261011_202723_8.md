# 研究报告：探索多模态模型在 2025 年的关键突破

## 1. 背景概览

2025 年是多模态模型从"能力演示"走向"体系化突破与生产落地"的转折年。其重要性体现在三个层面：**技术层面**，社区第一次把"模态在何处汇合"这一设计变量显式形式化，突破坐标从"模型规模/榜单分数"转向"融合位置与物理接口"；**评测层面**，图像问答类基准进入饱和区，区分力向长视频、长文档、音频与图表迁移，同时"榜单可信度与评测污染"首次被升级为基准设计的一等公民；**产业层面**，多模态能力已出现可量化的生产力转化——企业推理支出首次超过训练成本、API 调用成本较 2023 年下降 60–80%、超过 40% 的新增视觉语言模型部署于边缘端。

本报告整合五项任务（架构范式 / 旗舰模型 / 评测基准 / 落地产品化 / 局限风险）的检索结果，试图回答"突破发生在哪一层、被什么验证、转化为何种生产力、又留下哪些未解瓶颈"这一完整链条。**需特别说明**：部分来源带有 2026 年时间戳，属"回看视角"，混入 Qwen3.5/3.6、Gemini 3、GPT-5.5 等后续型号，引用时已按 2025 口径标注，跨源比较前须对齐版本与切分。

## 2. 核心洞见

**洞见一：2025 年架构突破发生在"融合层"与"tokenizer 层"，而非参数规模层。〔任务 1〕**
NMM Roadmap 给出 early-fusion 形式化定义 `F_early = Transformer(⋃ᵢ T(mᵢ))`，即所有模态由**同一统一算子 T** 映射进共享嵌入空间，绕过独立冻结编码器。由此形成 **late-fusion → mid-fusion → early-fusion** 三级原生度光谱。同时，统一 tokenizer 成为理解（自回归）与生成（扩散）两大阵营之间**唯一的物理接口**——若不统一，上层的"统一架构"只是接口层伪装（TokenFlow、Illume+ 为专项攻坚代表）。

**洞见二：开放权重阵营在 2025 年补齐"全尺寸谱系 + 原生多模态"缺口，上下文长度成为新的数量级分化维度。〔任务 2〕**
Qwen3 系列覆盖 0.6B–235B（dense + MoE），旗舰 Qwen3-235B-A22B 为 235B 总参数 / 22B 激活、约 36T tokens 预训练、119 种语言、Apache 2.0 开源；Qwen3-VL 提供 2B/7B/72B 且 7B 可单张 A100 80GB 部署。上下文形成 **1M > 256K > 200K > 128K** 的清晰分档，直接决定"可一次性吞下什么输入形态"。

**洞见三：长视频时序理解是 2025 年"突破"被最扎实量化验证的任务轴，同时图像 QA 基准已丧失区分度。〔任务 3〕**
Video-MME 官方榜给出可追踪的日期化证据链：video-SALMONN 2+（72B，10fps）以 **79.7%（w/o subs）/ 81.6%（w subs）、长视频 72.3/76.4** 刷新 SOTA（2025-09-28）。反之，MMMU-Pro 前四名压缩至 **81.0–82.8%，极差仅 2.4 分**，落入运行噪声。**基准的"信噪比"随能力提升而衰减**——同一基准在不同年份的决策价值完全不同。

**洞见四：突破已可转化为生产力，路径为"成本反转 + 端侧分层 + VLA 具身闭环"三者互为前提。〔任务 4〕**
企业 VLM 推理总支出首次超过训练成本；多模态 API 成本较 2023 年下降 60–80%；五服务拼装管线（OCR+Whisper+视觉模型+LLM+TTS）被单次多模态调用取代；全球 VLA 市场 2025 年 **USD 3.89B → 2035 年 USD 40.50B（CAGR 26.40%）**。四要素（成本、端侧、VLA、Agent）并非并列，而是耦合系统：没有成本下降，端侧下沉不划算；没有端侧低时延，实时语音与 VLA 控制环无法成立。

**洞见五："突破 = 瓶颈的函数"：2025 年的进展是对具体缺陷的定向回应，而非问题被解决。〔任务 5〕**
多模态 CoT、工具增强、时序感知激活工程等突破，恰好逐一对应长视频时序幻觉、注意力坍缩等缺陷；但其共同特征是 (a) 需专门构造的数据集/工具箱，(b) 在特定模型与特定基准上验证，(c) 以推理成本或理解力为代价换取可信度。因此"关键突破"宜表述为**"瓶颈被部分、条件性地缓解"**。

## 3. 证据与数据

### 3.1 架构层（任务 1）

| 层级 | 定义 | 代表模型 |
|---|---|---|
| late-fusion | 冻结独立编码器 + 浅层 projector 桥接 | LLaVA、DeepSeek-VL、CogVLM、Qwen-Audio |
| mid-fusion | 多编码器特征注入联合 backbone，保留模态感知边界 | — |
| early-fusion | 统一算子 T 映射进共享空间（born-native） | Transfusion、Chameleon、AnyGPT、Show-o2 |

- **统一 tokenizer 词表扩张代价**（决定新模态 embedding 能否端到端联合训练）：Chameleon 扩 **8,192**；Emu3.5 扩 **32,768**；AnyGPT 追加 **8,192 image + 1,024 speech + 8,192 music** tokens。
- **统一理解与生成的三路线**：diffusion-based / autoregressive-based / hybrid；Show-o（共享 Transformer 同时做 AR 文本 + 掩码图像 token 扩散）、Show-o2（AR 文本 + 视觉 flow matching）、OneCat（Qwen2.5 初始化 decoder + 模态专属 expert）。**共性：均以预训练语言 backbone 初始化，而非全组件从零训练。**
- **any-to-any 对偶性分类**：Multi-to-Text（Qwen2.5-VL、InternVL-3.5）/ Multi-to-Target（Qwen3-Omni、Wan2.2）/ Multi-to-Multi（BAGEL、Show-o2、Emu3.5、Janus-Pro）；M2-omni 覆盖 text/image/video/audio；Moshi 支持 text↔audio 双向。
- **效率全栈（MAS）**：Model 层（统一 vs 专用编码器、稀疏专家路由）/ Algorithm 层（token 压缩、剪枝、量化、蒸馏、投机解码）/ System 层（KV cache、边缘-云协同、软硬协同）；FastVLM、NVILA 通过 CUDA-graph 原生兼容把架构效率直接转为 wall-clock 收益。
- **因果动因**：DMML survey 的 **bridge bottleneck**——late-fusion 先分别处理文本与图像再浅层桥接形成信息瓶颈，解释为何 late-fusion 下继续堆参数收益递减。

### 3.3 评测层（任务 3）

- **长视频时序链条**：Video-MME（900 视频 / 254 小时 / 2700 QA，11s–1h）。Gemini 1.5 Pro（2024-06）75.0/81.3 → GPT-4o 71.9/77.2 → Keye-VL-1.5（8B，2025-08）73.0/74.0、长视频 67.1 → **video-SALMONN 2+（72B，2025-09）79.7/81.6、长视频 72.3/76.4**。**小模型追平大模型**是本年关键性质变化。
- **基准饱和**：MMMU-Pro 前四 81.0–82.8%（极差 2.4）；MMMU 上 Qwen3.5-397B-A17B 达 85.0%；MMBench SenseNova-U1-A3B-MoT 91.6%；AI2D 96.2% 近饱和。
- **新差异化轴**：DocVQA Claude Opus 4.7 **93.0%**（50+ 页长文档切成 5–8 分差）；ChartQA GPT-5.5 **92.1%**；MMAU 音频 Qwen3.5-Omni-Plus **82.2%**；GenEval BLIP3o-NEXT **0.910**；Qwen 3.5 Omni 实时 ASR **sub-300ms 首 token、95%+ 准确率**。
- **可信度治理（最硬证据）**：Video-MME-v2 采用**分组非线性评分 (N/4)² + First-Error Truncation 首错截断 + 先验泄漏检测**。同一模型 Gemini-3-Pro 平均 66.1% 在非线性打分下降至 **49.4%**，Gemini-3-Flash 由 61.1% 降至 **42.5%**——即约 **16–19 个百分点的"虚高分"被评测机制本身揭示**。数据成本可量化：**3,300 人工时**（标注 2,200h / 12 专家，质检 1,100h / 50 专家），产出 **800 视频 × 4 题 × 8 选项**。
- **评测哲学迁移**：从"答案正确性"转向"推理链有效性"——L1 多点信息聚合 → L2 时序理解 → L3 时序复杂推理；分组方式分 Capability Consistency 与 Reasoning Coherence。
- **性价比维度可量化**：llm-stats 榜上 Qwen3.5-35B-A3B 以 **$0.10/$0.95 拿到 0.825**，与 122B 的 0.839 仅差 1.4 分（稀疏 MoE 为主要解释）。

### 3.4 落地与产品化（任务 4）

- **市场**：VLA 市场 2025 年 **USD 3.89B → 2035 年 USD 40.50B（CAGR 26.40%）**；软件组件贡献最大收入份额，机器人为主导应用，北美份额最高、亚太增速最快、制造业终端增速最快。
- **端侧**：**>40% 新增 VLM 部署在边缘/端侧**；Apple Intelligence 本地运行于 iPhone 16 Pro+/iPad M4/Mac M4；Pixel Gemini Nano 以 **<30 亿参数**完成本地图像理解与摘要；Snapdragon AI 支撑 Android 本地多模态。
- **成本反转**：企业 VLM 推理总支出首次超训练成本；API 成本较 2023 年降 **60–80%**。
- **具身闭环五步**：仿真预训练（NVIDIA Cosmos / Microsoft Magma）→ 小样本真实数据微调 → **VLA 高层规划 + 低层控制器实时电机指令分离** → 全链路可观测 → persona 仿真压测。时间线：2024/02 DeepMind RT-2 → 2024/05 NVIDIA Isaac → 2024/09 OpenAI 入局 → **2025/01 Tesla 端到端 FSD 纳入 VLA**。
- **Agent 三形态**：屏幕控制 / 实时语音 / 跨模态文档检索。三种架构取舍：串行处理（简单但丢上下文）、统一嵌入空间 ImageBind/CLIP（理解丰富但门槛高）、原生多模态（性能最佳但厂商锁定）。
- **可验证 ROI**：现场服务 Agent 使**上门次数减少 60%、年节省 $500K**。

### 3.5 局限性量化（任务 5）

- **长视频时序幻觉（最硬未解瓶颈）**：VITAL（CVPR 2026）对照实验显示，文本 CoT 预测 260.94–335.93s vs Ground Truth 297.00–339.00s，**IoU 仅 49.9%**；引入工具后 296.00–336.00s，**IoU 90.7%**。失败主因是**起点偏移约 36 秒**（边界幻觉），且思维链出现反复自我推翻（297.94 → 296.94 → 260.94 → 296.00），说明**推理步数增加并未提升证据稳定性**。
- **幻觉治理三难困境**：SmartSight（AAAI-26）指出既有方法 (1) 跨模型迁移性差，(2) 以牺牲视频理解为代价。其方案使 Qwen2.5-VL-7B 在 VRIPT-HAL 降幻觉 **10.59%**，同时 VideoMMMU **提升 8.86%**。规模证据：ACL 2026 综述配套列表收录 **42 个基准 + 52 种缓解方法 + 95 条目/78 篇论文**，且月度持续新增——方法数量爆炸本身即"无统一解法"的信号。
- **机制可解释进展（但是事后诊断）**：Temporal Attention Collapse（注意力坍缩到单帧/贫乏片段）、Visual Attention Vanishing（生成到某 token 后视觉注意力骤降，此后由语言先验驱动）；NeurIPS 2025 发现**幻觉敏感性取决于 temporal variation 而非任务类型**。反直觉结论：**贪心解码会遮蔽低幻觉答案**，每问 10 个采样至少 1 个幻觉更低（幻觉部分是"解码伪影"）。
- **空间/3D 推理洼地**：方向判断类任务前沿模型仅 **56% vs 人类 95.7%**。
- **评测范式在收紧**：Video-HolmesV2（ECCV 2026）要求长视频答案引用精确视听证据并以 evidence-aware scoring 惩罚"猜测"；Video-DPL 采用时间戳化感知证据 + 事实性过程奖励——其前提假设就是**当前模型普遍会伪造证据**。

## 4. 风险与挑战

**4.1 技术瓶颈尚未收口**
- **长视频时序幻觉**为跨 2025–2026 的持续性瓶颈，非年度事件；VITAL 仍依赖专门构建的 MTVR-CoT-72k / MTVR-RL-110k 数据集与 DGRPO 算法，成功率高度依赖外部工具箱与密集采样。
- **幻觉与成本直接冲突**：诊断/推断期方案普遍依赖多候选采样、对比解码或早期终止，与成本约束矛盾；且未触及预训练阶段的视觉-语言对齐缺陷（CLIP 仅关注显著物体，背景细节、计数、物体关系天然缺失，是幻觉的结构性来源）。
- **评测偏向"可验证任务"**：高分多来自多选基准；一旦要求"指证 + 时间戳"，性能与可信度即暴露，导致能力评估系统性乐观。

**4.2 数据与口径风险（引用结论时必须一并说明）**
- **市场口径重叠不可相加**：多模态 AI 整体市场（2025 年 USD 2.6B，CAGR 36.8%）、VLM 市场（USD 3.84B，CAGR 26.95%）、VLA 市场（USD 3.89B，CAGR 26.40%）规模相近但定义与增速不同，很可能源于统计边界差异（是否含硬件、系统集成、API 平台）。
- **榜单切分不一致会得出矛盾结论**：Video-MME w/o subs 上，官方榜首 video-SALMONN 2+ 79.7%、llm-stats 榜首 Qwen3.5-122B-A10B 0.839、CodeSOTA 榜首 Qwen3.6-27B 87.7%——差异大概率来自是否含字幕/音频、抽帧预算与版本代际，跨源比较前必须对齐 split。
- **单一厂商偏置**：llm-stats 该榜追踪的 10 个模型全为 Qwen 系列（0.839→0.651 随规模递减），更像"厂商内部分层榜"，不宜作为 SOTA 依据。
- **模型参数冲突**：Claude 4 上下文在来源间存在 **200K vs 64K** 冲突；Qwen3-VL 的 **256K** 与 Qwen3 基座报告的 **32,768** 口径不一致；"Qwen3 VL Embeddings"实为从生成式 VL 模型抽取表征（mean pooling / 指令调优 embedding prompt），**非专用嵌入模型**，与 Gemini Embedding 2 为不同范式。
- **时间线混杂**：部分来源标注 2026-04，属"2026 视角回看"，需以各模型 2025 官方技术报告为准。

**4.3 落地侧风险与空白**
- **端侧口径未披露**："超过 40% 部署在端侧"按设备数量、算力或推理次数统计会得出截然不同结论；端侧 <30 亿参数模型的真实能力边界缺量化，"哪些任务绝对不能下沉"仍是空白。
- **厂商锁定**：原生多模态模型性能最佳、API 最简，但迁移成本与议价能力丧失构成隐性负债，会在两三年后一次性偿付。
- **开源 VLA 商用采用率无数据**，短期更可能停留在研究与不受限场景；ROI 案例（60% 上门减少、$500K 节省）缺行业标注与样本量说明。
- **抓取缺口**：Yahoo Finance 页面正文因反爬/脚本渲染失败，VLM 市场区域与品类细分需改用 GlobeNewswire 原稿或其他一手来源。

**4.4 证据强度不均（须显式声明）**
- **GUI/Agent 类基准缺证据**：任务 3 来源未覆盖任何 GUI agent 榜单（OSWorld、ScreenSpot、AndroidWorld 类），"Agent 能力是否被量化验证"目前无证据。
- **安全与版权属弱证据覆盖**：本轮未获得 2025 年多模态模型的直接红队评测报告、版权/数据合规实证研究，也未获得统一的成本-效用量化对比（如每 token 成本 vs 幻觉率折衷曲线）。因此该维度**不应与前四条同等强度表述**。
- 此外，任务 5 的笔记本地持久化内容为空（正文仍显示"待补充"），其结论依赖任务总结文本，后续宜补写回笔记以保证可追溯性。
