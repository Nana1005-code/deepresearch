## 本轮新增：关键发现
1. 开源在「垂直感知」赛道（文档/OCR/图表/UI）已实质追平闭源，但在通用抽象推理上仍有可见差距。数据：Qwen3-VL-235B-A22B-Instruct 对标 Gemini-2.5-Pro、GPT-5；Qwen2.5-VL-72B MMMU 70.2、DocVQA 95.7%、ChartQA 87.3%、OCRBench 86.4%；InternVL3-78B MMMU 72.2（开源 SOTA）；对照闭源 GPT-5.2 MMMU 84.2%、ARC-AGI-2 52.9%，Claude Opus 4.5 MMMU 77.8%、SWE-bench 80.9%。
2. 竞争焦点从「参数与榜单」转向「上下文窗口 + 模态原生性」。Gemini 3 Pro 为 1M 上下文、原生多模态（文本/图像/视频/音频）；Qwen3-VL 256K 原生、可扩展 1M，支持秒级视频索引；Llama 4 Scout 宣称 10M 上下文。架构上「后装视觉」被原生多模态取代，视觉编码器从 CLIP 演进到 SigLIP 2（2025 年 2 月），改善多语言与定位能力。
3. 成本结构的核心事实：输出 token 价格是输入 token 的 3–10 倍，使开源自托管 + FP8/量化成为成本可控的关键杠杆。Qwen3-VL 提供官方 FP8 版本；gpt-oss-120b 中位输出 271.4 tokens/s；Gemini Embedding 2 约 $0.000025/千字符，3072 维支持 Matryoshka 截断至 768/1536 维，可省约 75% 存储与算力。
4. 端侧多模态在 2025 年由「演示」迈向「可用」。Gemma 3 从 4B 起支持多模态、含官方量化版、预训练覆盖 140+ 语言并开箱支持 35+ 语言（图像归一化 896×896→256 tokens 是其细粒度瓶颈）；Qwen3-VL-7B 可单卡 A100 80GB，4-bit 量化后 24GB VRAM 消费级硬件可跑；2B 版本面向边缘与低延迟；Gemma 4 26B MoE 仅 14GB、消费级 85 t/s（无视频输入）；Nemotron Cascade 2 30B 在 RTX 4060 Ti + RTX 3060 上约 54 t/s。
5. 落地范式从「看懂图片」转向「视觉驱动的行动」，许可条款成为真实商业约束。GLM-4.6V（106B / Flash 9B）支持原生多模态工具调用（图像/UI 截图直接作为工具参数、可解析图表与网页快照）与 UI 截图转 HTML/CSS/JS；Claude Opus 4.5 的 Computer Use Zoom 支持 IDE/终端精确交互；Qwen3-VL 可操作 PC/移动端 GUI。许可上呈三分格局：Apache-2.0（Qwen 系）、MIT/Modified MIT（DeepSeek、Kimi K2.5，后者 100M MAU 以下商用免费）、限制性许可（Llama License 700M MAU 上限、Gemma License、NVIDIA Open）。

## 代表模型素材（能力 / 成本 / 许可）
- 闭源：GPT-5.2（2025-12，MMMU 84.2%、ARC-AGI-2 52.9%）；Claude Opus 4.5（2025-11，SWE-bench 80.9%、MMMU 77.8%、成本约为 Opus 4.1 的 1/3）；Gemini 3 Pro（2025-11，1M 上下文、AIME 2025 100% with code execution、Deep Think 推理提升 2.5x）。
- 开源：Qwen3-VL（235B-A22B / 30B-A3B，Instruct 与 Thinking 双变体，32 语言 OCR）；InternVL3（1B–78B 七档，InternViT-6B-448px-V2_5 + Qwen2.5-72B，模块化可升级）；LLaVA-OV（0.5B/7B/72B，47 项基准）；Molmo（AI2，1B/7B/72B，PixMo 数据含 2D pointing 与开放训练数据）；Gemma 3（1B/4B/12B/27B，128K，1B 为 32K）；DeepSeek-OCR（Contexts Optical Compression，以视觉 token 压缩长文本）；MiniMax M3（428B/23B 激活，512K，原生图像+视频）。

## 落地场景清单
企业文档规模化处理与表单/发票解析；长视频秒级索引与时间戳问答；GUI/桌面与浏览器自动化（Computer Use、前端还原、CRM 更新、报表生成）；隐私敏感场景自托管（金融、医疗、政务）；端侧实时视觉（手机、无人机、AR 眼镜）；视觉检索与多模态 RAG（Gemini Embedding 2 vs Qwen3-VL embeddings：8K vs 32K 上下文、零基建 vs 私有部署）。

## 待验证 / 风险项
- 来源多为 2026 年回顾性文章，2025 年当期的真实定价与权重发布节奏需二次核验；
- 「追平」结论高度依赖基准选择，需补 MMMU-Pro、视觉幻觉、长上下文衰减等对抗性评测；
- 端侧吞吐数据（85 t/s、54 t/s）与具体硬件/量化组合强绑定，跨设备可比性有限；
- Kimi K3 权重与许可仍未公布，Kimi K2.5 的 Modified MIT 归属条款需法务复核。
