# 研究报告：探索多模态大模型在 2025 年的关键突破

## 1. 背景概览

2025 年是多模态大模型从「模态拼接」走向「原生统一」的范式切换年。行业主线由 late-fusion（独立视觉编码器 + 投影层 + LLM）转向 early-fusion（统一 tokenizer + 共享 backbone + 端到端跨模态训练）。本研究按五个任务拆解这一转变：**原生架构（任务 1）、评测基准（任务 2）、视频时序理解（任务 3）、多模态智能体（任务 4）、开源与落地（任务 5）**。

五条主线高度耦合：新架构拓展能力边界，新能力催生新评测，新评测暴露新短板，而成本结构与许可条款最终决定能力能否落地。其重要性在于，2025 年首次同时出现了**架构范式收敛**、**评测体系反污染化**、**视频从「看不全」到「看得准」**、**智能体从「看懂」到「操作」**、**开源在垂直任务上实质追平**这五项转折——但它们各自的成熟度差异极大，误判成熟度将直接导致架构选型与采购决策失误。

**证据可追溯性说明**：任务 3、4 的笔记已沉淀完整发现；任务 1、2 的笔记仍停留在「已创建、待执行」状态（未回填发现）；任务 5 的笔记本轮未返回。因此任务 1、2、5 的结论目前依赖任务总结层，尚未在任务笔记层二次固化，可追溯性弱于任务 3、4。本报告已逐项标注来源任务编号。

## 2. 核心洞见

**洞见 1｜原生架构已被「形式化」，2025 是分水岭而非口号年（任务 1）**
路线图工作首次把「原生度」量化为三级：**non-native（late-fusion）/ mid-fusion / early-fusion**，其中 early-fusion 形式化为 `F_early = Transformer(∪ᵢ T(mᵢ))`——绕过独立冻结编码器，所有模态由统一算子 T 映射入共享嵌入空间。其价值在于：此前「原生」是模糊营销词，如今具备可判定标准（是否共享计算路径 + 统一 tokenization + 端到端跨模态训练）。Apple 的实证缩放规律 `L(N,D)=E+A/N^α+B/D^β` 显示同等算力下 early-fusion 不劣于 late-fusion，且最优配置倾向 early-fusion + MoE。但「完全原生」尚未普及：多数模型仍是模态专属 tokenizer + 共享 backbone 的混合形态，对称 any-to-any 集中在 7B–34B 中量级。

**洞见 2｜榜单头部在收敛，但短板已清晰——感知/OCR 成熟，瓶颈转移到推理编排（任务 2）**
MMMU-Pro 通过三步反污染设计（LLM 过滤纯文本可答题、选项从 4 项扩至至多 10 项、vision-only 把题目嵌入截图）将随机猜测基线从 MMMU 的 22.1 压至 12.4–12.6。**最具方法学价值的消融结论是：显式 OCR prompt 几乎无增益**——意味着前沿 VLM 的视觉文字抽取已成熟，瓶颈已从「感知」转移到「推理编排 + 跨模态绑定 + 上下文关系理解」。前沿约 19 个月提升约 34 分，但前 12 名挤在 0.807–0.860（5.3 分区间），同时 ZeroBench 仅 23.0%，呈现「榜单饱和」与「真实盲区」并存。

**洞见 3｜长视频已工程可行，实时流才是真正前沿（任务 3）**
核心答案可概括为「**先注入时序、再压缩 token**」。STORM（NVIDIA）在 SigLIP 编码器与 LLM 之间插入**双向 Mamba 时序投影器**，先让每个视觉 token 携带全片上下文，再做时间平均池化（4:1）与训练无关的隔帧采样（2:1），合计 **8× token 压缩**，视觉算力降至约 1/8、推理约快 3 倍，在长视频基准上超过 GPT-4o。关键反直觉点：缺少 Mamba 模块时，单纯拉长视频 + 压缩会使基线 VILA 收益递减——**压缩必须建立在时序已编码的前提上**。而实时流引入了「因果约束 + 主动性」两重新问题（无法回看或预览未来帧 + 何时该开口），是比长视频更硬的瓶颈，2025 年底至 2026 年初才由 STC、StreamKV、CacheFlow、LiveStar 等系统性方案密集攻坚。

**洞见 4｜「看懂 → 操作」在窄域已跨越，但可用度被成功率系统性高估（任务 4）**
OSWorld 用 134 个**执行型评估函数**检验真实结果：原始榜单人类 72.36% vs 最佳模型 12.24%（GPT-4/Mixtral/CogAgent 等基线）；到 2026 年 6 月短任务达约 85%，但换到长程基准 OSWorld 2.0（人类中位约 1.6 小时），最佳系统仅 **20.6%**。**这两个数字之差是本领域最重要的事实**。失败模式高度可复现且为结构性缺陷：GUI grounding（坐标误判、重复误点、杂乱动态界面映射失败）、operational knowledge（应用语义不熟、菜单/设置误操作、试错循环）、long-horizon planning（步数一长成功率骤降，记忆/上下文跟踪/子目标分解弱），外加**环境噪声恢复失败**（意外弹窗、状态异常）。隐藏命门是效率——延迟主要来自规划与反思的模型调用，步数越靠后单步耗时可≥起始步 3 倍，端到端常达数十分钟（人类仅数分钟），顶尖 agent 仍需多 1.4–2.7× 步数。

**洞见 5｜开源已在垂直感知实质追平，但「追平」必须分层谈（任务 5）**
开源与闭源的差距不是均质曲线而是**分层结构**：文档/OCR/图表等「高信息密度、低抽象度」任务已处同一梯队（InternVL3-78B MMMU 72.2；Qwen2.5-VL-72B DocVQA 95.7%、OCRBench 86.4%），但抽象推理与长链路代理仍有可见差距（GPT-5.2 MMMU 84.2%、ARC-AGI-2 52.9%；Claude Opus 4.5 MMMU 77.8% + SWE-bench Verified 80.9%）。成本的核心事实是**输出 token 单价为输入的 3–10 倍**，开源的真杠杆不在权重免费，而在 FP8/量化 + 自托管。许可已形成三分格局（Apache-2.0 / MIT / 限制性 700M MAU 上限），须优先于榜单名次复核。

## 3. 证据与数据

**架构与缩放（任务 1；笔记未回填，源自任务总结层）**
- Early-fusion 缩放规律：`L(N,D)=E+A/N^α+B/D^β`；稠密 N∝C^0.53、MoE N∝C^0.36、D∝C^0.66
- 代表模型时间线：Janus-Pro 7B（2025.01）、Llama-4 Scout 109B-A17B（2025.04）、BAGEL 14B-A7B（2025.05）、Show-o2 7B（2025.09）、OneCAT 9B-A3B（2025.09）、Qwen3-Omni 30B-A3B（2025.09）、Emu3.5 34.1B（2025.10）
- 稳定性痛点：Chameleon 在 8B/1T tokens 出现 late-training 发散，根因是多模态共享表征时视觉生成需极端激活值与文本信号竞争，靠 QK-Norm 等关键点归一化解决
- 统一 tokenizer 工作：DualToken、SemHiTok（语义引导层级码本）、V2Flow（视觉 tokenization 与 LLM 词表对齐）、Ming-UniVision（统一连续 tokenizer）

**评测基准（任务 2；笔记未回填，源自任务总结层）**
- GPT-4o：MMMU 69.1% → MMMU-Pro 51.9%（Δ −17.2）；全模型相对 MMMU 下降 16.8%–26.9%
- SOTA 曲线：GPT-4o ≈0.52（2024-09）→ 前沿并列 ≈81%（2026-03）→ GPT-6.1 Sol 0.860（2026-10）
- 开源梯队：MMMU-Pro 上 30B 级（0.74–0.77）已超 2024 年 GPT-4o；Qwen3 VL 235B Thinking 0.693 反低于 Qwen3.6-35B-A3B 0.753——参数规模不再是主因
- 成本三角：GPT-5.6 Luna 0.784 @ $0.20/$1.20 vs GPT-5.5 0.832 @ $5/$30（约 5% 分差换 25 倍成本）；Claude Opus 5.5 精度 92.2% 但延迟 737.53s，对比 Kimi K3 92.6% / 49.38s
- 短板：ZeroBench 仅 23.0%（Kimi K3）、33.6%（Gemini 3.5 Flash）；OfficeQA Pro 全域 62.4%–84.6%
- 覆盖缺口：29 个被追踪基准中仅 4/29 进入加权证据集，且**无任何视频基准**

**视频时序（任务 3；笔记已沉淀）**
- STORM：双向 Mamba + 时间池化 4:1 + 隔帧采样 2:1 = 8× 压缩；视觉算力≈1/8、推理约快 3×；缺失 Mamba 则收益递减
- 流式代表工作：STC（CVPR 2026，STC-Cacher 复用时间相近帧 ViT 特征 + STC-Pruner 在 LLM prefill 前按时空相关性/新颖度剪枝）、StreamKV（AAAI 2026，分段 KV cache 检索与压缩）、CacheFlow（压缩式流式记忆）、LiveStar（NeurIPS 2025）、MMDuet2（ICLR 2026）
- 流式触发机制：EOS token 触发、专用分类器、困惑度校验、视觉检测；流式训练含「静默帧虚假生成惩罚 + 最大化 EOS 预测准确率」的专用损失
- 数据演进：TimeIT（2023, 125K）→ VTimeLLM（2024, 134K）→ VTG-IT-120K（2025，标准化时间 token）→ TimeLens-100K（多步验证）→ MTVR（72K SFT + 110K RL）→ VideoMarathon（3.3M 小时级）
- 长期记忆转向实体中心：M3-Agent

**智能体（任务 4；笔记已沉淀）**
- OSWorld：369 Ubuntu + 43 Windows 任务、134 执行型评估函数；环境支持 pyautogui 真实鼠标键盘事件、可从「进行中状态」初始化、多模态观测（截图 + a11y 树 + 终端输出）；含约 8% 不可行任务，测试「拒绝/识别不可完成」的元能力
- 基准迭代：OSWorld（2024-04）→ OSWorld-G（564 样本 grounding 套件 + Jedi 数据集，2025-05）→ OSWorld-Human（2025-06）→ Verified（2025-07-28，修复社区样例 + AWS 支持，评估 <1 小时）→ 2.0（2026-06-26）
- 时间线：12%（2024-04）→ 85%（2026-06）；2.0 最佳 20.6%（人类中位 1.6 小时）
- 方法学影响：经验增强层次规划、多智能体协作、GUI + 代码混合控制均以 OSWorld 为评估场；推动「截图 + a11y 融合感知 + 显式 grounding 模块 + 记忆/反思机制」架构转向

**开源与落地（任务 5；笔记本轮未返回，源自任务总结层）**
- 上下文：Gemini 3 Pro 1M 原生多模态、Qwen3-VL 256K 原生可扩至 1M、Llama 4 Scout 宣称 10M
- 端侧：Gemma 3 从 4B 起多模态（1B/4B/12B/27B，128K 上下文、140+ 语言预训练、开箱支持 35+ 语言）；Qwen3-VL 2B/7B/72B，7B 可单张 A100 80GB，4-bit 量化后 24GB VRAM 消费级可跑；Gemma 4 26B MoE 约 14GB / 85 t/s；Nemotron Cascade 2 约 54 t/s；gpt-oss-120b 中位输出 271.4 tokens/s
- 降本：Gemini Embedding 2 默认 3072 维，经 Matryoshka Representation Learning 可无损截断至 768/1536，存储与算力成本降约 75%
- 范式转向：GLM-4.6V 端到端视觉驱动工具调用（图像/UI 截图/文档页可直接作工具参数，无需先转文本）
- 端侧边界：Gemma 3 将图像归一化到 896×896、编码为 256 token，构成细粒度与非标准分辨率/长宽比场景的硬瓶颈；Gemma 4 尚无视频输入；Gemma 3 不支持长视频或音视频联合分析

## 4. 风险与挑战

1. **笔记与总结层不同步**：任务 1、2 笔记仍为「已创建、待执行」，未回填发现；任务 5 笔记本轮未返回。这三条结论目前依赖任务总结层，未在笔记层二次固化，可追溯性弱于任务 3、4。
2. **证据时间错位**：任务 2、5 的多份来源为 2026 年回顾性文章，模型版本与定价跨年混用（GPT-6.1 Sol、Qwen3.8 Max、Gemma 4、Kimi K3 等属 2026 语境）。2025 年当期的真实发布节奏与价格需二次核验。
3. **评测口径不一致与饱和污染**：BenchLM 表格列名映射存在歧义（如 CharXiv 91.32 vs 表中 83.4）；MMMU-Pro 的 with tools 与不带工具分数不可比；前 12 名挤在 5.3 分区间，叠加公开测试集长期使用，污染风险持续。
4. **评测覆盖缺口**：VideoMME、MathVista、SpatialEval、MMBench、ChartQA 的 2025 SOTA 证据为零；幻觉类仅有基准名称（SimpleVQA、Facts-VLM、V*、BabyVision）而无分数。
5. **原生架构的工程代价被低估**：Chameleon 训练发散表明 early-fusion 需要新的稳定性工程；视频侧「先时序再压缩」说明压缩会破坏时序证据，二者之间的可证伪权衡曲线尚未建立。
6. **真实可用度与榜单脱节**：智能体短程 85% vs 长程 20.6%；延迟与步数效率长期未被当作一等指标，端到端常达数十分钟而人类仅需数分钟。
7. **具身智能证据缺失**：2025 年真机泛化、操作成功率、失败模式的一手实证数据本轮完全缺失，是最大空白（任务 4 已明确列为待补充项）。
8. **法务与商用风险**：Kimi K2.5 的 Modified MIT 归属条款、Llama 的 700M MAU 上限、Gemma / NVIDIA Open 商用红线均需法务复核；生态「开放度」不等于「可商用度」。
9. **值得单独验证的开放问题**：流式主动交互中「时机正确性」（该沉默时是否沉默）缺乏量化基准；长视频压缩与证据忠实度之间的权衡曲线尚未建立；early-fusion 在 >40B 规模是否仍保持缩放优势，或 MoE 才是关键放大机制，尚无定论。
10. **暂无相关信息的项**：具身智能 2025 侧的一手实证数据、闭源 API 实际单价与自托管 TCO 测算，本轮均未获取。
