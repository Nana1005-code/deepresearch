# 任务 1: 前沿模型架构

【任务概览】梳理 2026 年视觉文档问答（Visual Document QA）在模型架构层面的最新进展，明确技术主线与代表工作。本轮已获取 DocVQA 官方站、DocVQA2026 GitHub 官方评测仓库、Doc-V* 论文摘要、llm-stats DocVQA 榜单、DL_tasks 综述等五路来源，形成"基准换代—路线收敛—张力未解—分域短板—系统级博弈"五段式判断。
【系统提示/意图】回答“2026 年主流 DocVQA 模型长什么样、相比 2024 的关键变化是什么”，聚焦高分辨率图像编码、OCR-free 端到端范式、原生多模态 LLM（GPT-5 系列 / Gemini 3 / Claude 4.x / Qwen3-VL 等）在文档场景的能力边界。当前已可用 2026 年真实评测数据（Gemini 3 Pro Preview / GPT-5.2 / Gemini 3 Flash / GPT-5 Mini）替代此前的推测性描述。
【检索方向】(1) 高分辨率动态切图与视觉 token 压缩；(2) 布局/表格/图表的结构感知编码；(3) OCR-free 与 OCR-based 混合路线对比；(4) 开源 vs 闭源模型在 DocVQA 类任务上的性能与成本。本轮补充：(5) 多页长文档的检索式视觉推理（ColPali 系、Doc-V* 系）；(6) 评测规则/参数预算对架构选择的反向约束。
【来源概览】arXiv 2025-2026 新论文、模型技术报告、Papers with Code、官方模型卡。本轮新增已核实来源：docvqa.org（含 ICDAR2026 挑战赛公告）、GitHub VLR-CVC/DocVQA2026（官方评测脚本与 baseline prompts，RRC 平台 ch=34）、arXiv:2604.13731（Doc-V*）、llm-stats.com/benchmarks/docvqa（截止 2026-10-10 榜单）、bthek1.github.io/DL_tasks（文档问答综述）、HuggingFace VLR-CVC/DocVQA-2026。
【任务总结/待办】产出“架构路线图 + 代表模型对照表”，标注每条路线的适用文档类型与局限。

【本轮新增发现 1｜基准换代导致"能力边界塌陷"】旧 DocVQA（2020，50,000 问题 / 12,000+ 文档图像）已被刷至饱和：llm-stats 2026-10-10 榜单 28 个模型平均 0.9，榜首 Qwen2.5-VL-72B Instruct 0.964、Qwen2.5-VL-7B 0.957、Claude 3.5 Sonnet 0.952、Qwen2.5-Omni-7B 0.952、Mistral Small 3.2 24B 0.949、Llama 4 Maverick/Scout 0.944、GPT-4o 0.928，人类上限 94.36%。而 DocVQA2026（ICDAR2026，Multimodal Reasoning over Documents in Multiple Domains，覆盖 business report / science paper / slide / poster / map / comic / infographic / engineering drawing 八域）上，Gemini 3 Pro Preview 仅 0.375、GPT-5.2 0.350、Gemini 3 Flash Preview 0.3375、GPT-5 Mini 0.225。结论：旧基准上的"SOTA"主要来自分辨率与解码策略红利，而非文档推理能力；新基准才是 2026 年的真实能力刻度。
【本轮新增发现 2｜原生多模态 LLM 已吞并另两条主线，且规模不再是决定性变量】榜单前列几乎全部为原生 MLLM（Qwen2.5-VL、Llama 4、Pixtral/Pixtral-Large、DeepSeek-VL2 三档、Grok-2、Nova Pro/Lite、Phi-4-multimodal、Gemma 3 系）。小模型效率证据密集：Qwen2.5-VL-7B 0.957 逼近 72B 的 0.964；Phi-4-multimodal-instruct 6B 0.932；Cohere North Micro Vision 2B 0.921；Liquid AI LFM2.5-VL-3B 0.911；DeepSeek-VL2-Tiny 3B 0.889；Llama 3.2 11B 0.884。参数规模与得分近弱相关，胜负手在于动态分辨率切图 + 视觉 token 压缩效率。
【本轮新增发现 3｜OCR-free 端到端 vs 视觉检索的核心张力仍未解】Doc-V*（arXiv:2604.13731）明确指出多页 DocVQA 的"容量 vs 精度"取舍：端到端 OCR-free 模型随文档长度增长扩展性差（scale poorly with document length），视觉检索式流水线则脆弱且被动（brittle and passive）；其提出 coarse-to-fine 交互式视觉推理作为第三条路。
【本轮新增发现 4｜分域性能暴露高分辨率编码的真实短板】DocVQA2026 分域数据：Infographics 最高 0.700（Gemini 3 Pro）、Slide 0.700（Gemini 3 Pro）、Business Report 0.600（GPT-5.2）、Engineering Drawing 0.500（Gemini 3 Flash）、Science Paper 0.500（Gemini 3 Flash）；而 Maps 上 Gemini 3 Pro/Flash 均为 0.000、GPT-5.2 0.200、GPT-5 Mini 0.100；Science Poster GPT-5.2 与 GPT-5 Mini 均为 0.000；Comics 仅 0.400（Gemini 3 Flash）。规律：文本密集 + 版式规整（信息图/幻灯片/报告）已基本解决；矢量图形、空间拓扑、跨面板叙事（地图/漫画/工程图/海报）仍在失败区。另有工程约束：OpenAI 系 API 单文件 50MB 上限，数据集内多张漫画超限，直接计为失败。
【本轮新增发现 5｜评测规则与参数预算把 SOTA 从"单模型"推向"系统级架构"】DocVQA2026 参赛分三档（按总参数量，含非激活参数；agentic 系统须累加所有使用模型的参数），输出强制 FINAL ANSWER: 前缀，数字/日期/单位需规范化（如 50 kg、10 USD、YYYY-MM-DD、1,000），文本走 ANLS 松弛匹配，评测脚本与 Master Prompt（get_evaluation_prompt()）在 GitHub 开源，赛道托管于 RRC（rrc.cvc.uab.es/?ch=34），成果发表于 ICDAR 2026（维也纳）。历史脉络：DocVQA 2020 → InfographicVQA 2021 → 2024 ColPali 检索优先（VLM 直接嵌入页面图像 + late interaction 跳过解析）→ 2026 多域多模态推理解题。
【本轮新增发现 6｜生产环境与学术 SOTA 的分叉】综述来源指出，工业界获胜范式常为级联：专用 OCR → 结构化 markdown → 文本 LLM 回答；学术侧则走向 retrieval-first document AI（2024-2026）。二者在成本、可控性、长文档扩展性上取舍不同。
【待办更新】已完成：三条主线边界与代表工作定位、旧/新基准对比表素材、分域短板清单。待补充：Qwen3-VL / Claude 4.x / InternVL 系在 DocVQA2026 上的实测分域数据；高分辨率切图（动态分辨率、AnyRes、token 压缩比）具体机制对比；多页长文档方法与 ColPali/Doc-V* 的定量对照。
